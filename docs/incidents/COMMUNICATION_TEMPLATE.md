# Communication Template

## Comunicação interna (durante o incidente)

```
Incident ID:        INC-YYYYMMDD-XXXXXXXX
Severity:           SEV-1 | SEV-2 | SEV-3 | SEV-4
Status:             <status atual do lifecycle>
Impact:             <resumo do impacto, sem dado pessoal>
What is affected:   <sistemas/funcionalidades afetadas>
What is not affected: <o que continua funcionando normalmente>
Actions underway:   <o que está sendo feito agora>
Next update:        <quando a próxima atualização será enviada>
Owner:              <papel responsável por esta comunicação>
```

Sem dados pessoais. Nunca incluir segredo, token, ou identificação de titular de dados.

## Comunicação externa

**Comunicação externa (a clientes, ao público, à ANPD) depende de aprovação jurídica/gestão.** Este
template não gera nem envia nenhuma mensagem externa automaticamente — nenhuma notificação a clientes é
enviada sem essa aprovação explícita.
