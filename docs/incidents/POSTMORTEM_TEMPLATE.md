# Postmortem Template

Sem linguagem punitiva — o objetivo é aprender e corrigir, nunca atribuir culpa individual.

```
Summary:                <o que aconteceu, em 2-3 frases>
Impact:                 <quem/o que foi afetado, por quanto tempo>
Detection:              <como foi detectado — evento H6, revisão manual, terceiro>
Timeline:               <referência ao Incident Record — docs/incidents/INCIDENT_TEMPLATE.md>
Root Cause:             <causa técnica/processual raiz>
Contributing Factors:   <fatores que agravaram ou atrasaram a resposta>
What Went Well:         <o que funcionou no processo/resposta>
What Went Wrong:        <o que não funcionou — sem apontar indivíduos>
Containment:            <como foi contido>
Recovery:               <como foi recuperado>
Corrective Actions:
  - [Tarefa] | [Responsável] | [Prazo] | [Critério de Aceite]
  - [Tarefa] | [Responsável] | [Prazo] | [Critério de Aceite]
Owner:                  <responsável pelo acompanhamento do postmortem>
Due Date:               <prazo de conclusão das ações corretivas>
Verification:           <como será confirmado que as ações corretivas foram efetivas>
```

## Prazo interno sugerido (política interna, não obrigação legal)

Para SEV-1/SEV-2, recomenda-se concluir o postmortem em até 5 dias úteis. Esta é uma **recomendação
interna**, não uma obrigação legal ou regulatória — na ausência de uma decisão organizacional formal
sobre SLA de postmortem, tratar como sugestão, não regra.
